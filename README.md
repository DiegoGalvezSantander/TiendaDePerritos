# FullStack2TiendaMascotas

## 🔗 Repositorio
https://github.com/TU_USUARIO/FullStack2TiendaMascotas

## 📋 Descripción
Proyecto frontend de tienda de mascotas desarrollado para la Evaluación Parcial 1 de DSY1104 (Duoc UC). Incluye tienda pública, carrito y panel administrador con roles (Administrador / Vendedor / Cliente).

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 (externo, variables, responsive)
- JavaScript ES6 (validaciones, localStorage)

## 🚀 Cómo ejecutar
1. Clonar el repositorio.
2. Abrir `index.html` en el navegador.
3. Registrarse y luego iniciar sesión para acceder al panel admin.

## 👥 Integrantes y tareas
- Nombre 1 — HTML estructura y navegación
- Nombre 2 — CSS y diseño responsivo
- Nombre 3 — JavaScript (validaciones, carrito, admin)
