# TiendaDePerritos - Tienda Online

## 🔗 Repositorio
https://github.com/DiegoGalvezSantander/TiendaDePerritos

## 📋 Descripción
Tienda online de productos para mascotas desarrollada con HTML, CSS y JavaScript vanilla. Incluye catálogo de productos, carrito de compras con persistencia en localStorage, sistema de login con roles (Administrador, Vendedor y Cliente) y panel de administración.

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3 (externo, variables, responsive)
- JavaScript ES6 (validaciones, localStorage)

## 🚀 Cómo ejecutar
1. Abrir `index.html` en el navegador.
2. Navegar por el catálogo de productos.
3. Para acceder al panel de administración: `IniciarSesion.html` con las credenciales de admin.
